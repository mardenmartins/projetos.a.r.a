# 🤖 S.A.R.A.

> Sistema web desenvolvido como projeto acadêmico no curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

---

## 📋 Sobre o projeto

**S.A.R.A.** é uma aplicação web desenvolvida com o objetivo de aplicar, na prática, conhecimentos adquiridos ao longo da formação em **Análise e Desenvolvimento de Sistemas**.

O projeto foi desenvolvido de forma colaborativa, utilizando tecnologias de desenvolvimento web e conceitos de programação, estruturação de interfaces, manipulação de dados e controle de versão.

A proposta do projeto é unir **funcionalidade, organização e usabilidade** em uma aplicação web desenvolvida integralmente pela equipe.

---

## 🎯 Objetivo

O principal objetivo do **S.A.R.A.** é proporcionar uma experiência prática de desenvolvimento de software, permitindo à equipe aplicar conceitos estudados em sala de aula na construção de uma aplicação funcional.

Durante o desenvolvimento, foram trabalhados conceitos como:

- Desenvolvimento Web;
- Estruturação de páginas;
- Desenvolvimento de interfaces;
- Programação em JavaScript;
- Manipulação de dados;
- Autenticação de usuários;
- Organização de código;
- Controle de versão;
- Desenvolvimento colaborativo.

---

## 🚀 Como executar o projeto

### Pré-requisitos

Para executar o projeto localmente, recomenda-se ter instalado:

- [Git](https://git-scm.com/)
- [Visual Studio Code](https://code.visualstudio.com/)
- Um navegador atualizado

### 1. Clone o repositório

```bash
git clone https://github.com/mardenmartins/projetos.a.r.a.git
```

### 2. Entre na pasta do projeto

```bash
cd projetos.a.r.a
```

### 3. Execute a aplicação

Abra o arquivo:

```text
index.html
```

em seu navegador.

Para facilitar o desenvolvimento, recomenda-se utilizar a extensão **Live Server** no Visual Studio Code.

## 🎓 Projeto acadêmico

O **S.A.R.A.** foi desenvolvido no contexto acadêmico do curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

O projeto tem como finalidade proporcionar à equipe uma experiência prática envolvendo as diferentes etapas do desenvolvimento de uma aplicação, desde a organização inicial até a implementação e publicação.

A experiência também permite o desenvolvimento de competências relacionadas ao **trabalho em equipe**, **controle de versões**, **organização de código** e **resolução de problemas**.
